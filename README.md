# Lifespan inequality trends among Canadian provinces and territories, 1960&ndash;2019

This project calculates lifespan inequality for each Canadian province/territory. I replicate the article by Brown, Lariscy, and Walker (2023) that calculated US state-level trends in lifespan variability but with Canadian provinces/territories.

Data are drawn from the [Canadian Human Mortality Database](http://www.bdlc.umontreal.ca/chmd/).

This paper was accepted for presentation at the 2027 PAA meeting.
